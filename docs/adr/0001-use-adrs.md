# 0001. Use ADRs

Status: Accepted · Date: 2026-10-24 · Design section: —

## Context

The design document leaves defaults, naming and library choices to whoever
implements each part. Those choices need to be findable later.

## Decision

Record them here, one file each, and link them from the PR that makes them.

## Consequences

The design document stays about architecture. Reviewers can see why something
is the way it is without digging through PR threads.
