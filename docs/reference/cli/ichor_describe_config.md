## ichor describe config

Show a node's rendered configuration, each value tagged with the layer that set it

### Synopsis

describe config renders the node's complete configuration the way the
controller does and prints every value with its origin layer. Secrets are
masked ("***") by the same code ichor-ui uses -- this works without ichor-ui,
reading the CRs and the secrets bundle with your own Kubernetes access.

```sh
ichor describe config NODE [flags]
```

### Examples

```sh
  ichor describe config cp-1
  ichor describe config worker-3 -o yaml
```

